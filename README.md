# My-To-do-task
To-Do List AppA simple To-Do List App built with HTML, CSS, and JavaScript. This app allows users to create an account, log in, and manage their tasks with features like adding, removing, and tracking task status.

Features- User authentication:
    - Sign up for a new account
    - Log in to existing account
- Task management:
    - Add tasks with date and time
    - Assign priority levels (High, Medium, Low)
    - Track task status (Pending, Completed)
    - Remove tasks

Technologies Used- HTML
- CSS
- JavaScript

Usage1. Open index.html in a web browser
2. Sign up for a new account or log in to an existing one
3. Add tasks 
4. View and manage tasks in the list

Future Improvements- Data persistence (local storage or backend integration)
- Task editing
- Filtering and sorting
